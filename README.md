# Student Performance Prediction System (EBM)

A complete academic project using an **Explainable Boosting Machine (EBM)** to estimate whether a student is likely to pass based on study-related and academic-history variables. It includes data acquisition, preprocessing, training, evaluation, explainability, plots, a Streamlit interface, and a report template.

## Important academic note
The project uses the public **UCI Student Performance** dataset (Portuguese secondary-school students). The data are not Sri Lankan university records. Do not describe them as local Sri Lankan data. If your lecturer strictly requires a locally collected dataset, replace the source data with consented, anonymized local data and update the report. The dataset contains 649 students across mathematics and Portuguese subjects; this project uses the mathematics file.

This is an educational demonstration, not a validated system for real student placement or high-stakes decisions. Predictions must not be used to punish, label, or deny opportunities to students.

## Why EBM?
Your covered list includes Linear Regression, Logistic Regression, Decision Trees, Random Forest, SVM, KNN, XGBoost, AdaBoost, Gradient Boosting, LightGBM and CatBoost. EBM is not on that list. It is a glass-box generalized additive model boosted with trees, designed to provide interpretable feature effects. Confirm with your lecturer that it counts as a new algorithm before submission.

## 1. Setup (Windows)
Install Python 3.10 or 3.11, then open Command Prompt in this project folder:

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 2. Download dataset and train/evaluate
```bash
python src/train_model.py
```
The script downloads the dataset using `ucimlrepo` and saves the source file under `data/`. Internet is needed the first time. It creates `models/ebm_model.joblib`, `models/feature_columns.json`, metrics and explainability outputs in `outputs/`.

## 3. Launch the interface
```bash
streamlit run app.py
```
If the model does not exist yet, train it first. The app lets a user enter a student's academic/study information and view the model's prediction, probability, and global feature-importance chart.

## Dataset and target
- Source: UCI Machine Learning Repository, Student Performance, DOI: https://doi.org/10.24432/C5TG7T
- Source dataset: mathematics (`student-mat.csv`), 395 records.
- Target: `pass` when final grade `G3 >= 10` out of 20, otherwise `at_risk`.
- To avoid leakage, `G1`, `G2`, and `G3` are excluded from predictors. The target is derived from G3, but G3 is never used as an input feature. The model therefore uses information available before the final grade.
- The project excludes sex and other direct demographic variables from model features, but other variables can still act as proxies. This does not eliminate bias.

## Files
- `src/train_model.py`: data acquisition, preprocessing, split, training, evaluation, charts, EBM explainability.
- `app.py`: Streamlit front end.
- `requirements.txt`: dependencies.
- `reports/assignment_report.pdf`: initial report draft (must be updated with actual results after training).
- `outputs/`: generated metrics, confusion matrix, ROC curve, feature importance.
- `data/`: downloaded dataset.
- `docs/REPORT_GUIDE.md`: report-writing guide and interpretation prompts.
